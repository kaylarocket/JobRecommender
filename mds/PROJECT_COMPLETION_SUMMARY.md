
### Typography
```
Font Family: Plus Jakarta Sans (Google Fonts)
Sizes: 12px - 57px
Weights: 500, 600, 700, 800

```

### Spacing Grid
```

```

### Border Radius
```
8px  - Small elements (chips, small buttons)
12px - Standard elements (inputs, filters)
16px - Cards and larger components
20px - Large sections
50%  - Circles and avatars
```
